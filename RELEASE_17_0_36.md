## Complete System Administrator Directory and Desktop Repair

This release fixes the System Administrator desktop regression and makes the main System Administrator page the complete source of navigation for every internal admin tool.

### Changes
- Replaced the incomplete seven-card System Administrator home with all 21 internal admin subpages, grouped by purpose.
- Removed the native “All System Administrator tools” select that could expand across and visually destroy the desktop page.
- Added a stable current-section indicator plus one-click return to the complete System Administrator directory on every subpage.
- Kept the Concept 1 charcoal/bronze visual language across the complete directory and internal admin subpages.
- Tightened desktop, tablet, and mobile grids so cards and panels do not overflow their containers.
- Preserved the 17.0.35 QA seed host fix, 17.0.34 drawer reset/PWA Back behavior, Spanish coverage, presence retirement, and testing-domain pin.
